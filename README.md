# Real-World Data Project (Retail Sales Analysis)

## Overview

This project analyzes retail sales data to identify business trends, product performance, and regional sales patterns.

## Objectives

* Analyze retail sales performance
* Identify high-performing products
* Compare sales across regions
* Generate business insights through visualizations

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Dataset

Retail Sales Dataset

## Analysis Performed

* Statistical summary
* Product sales analysis
* Regional sales analysis
* Product distribution visualization

## Key Findings

* Laptops generated the highest sales revenue.
* Regional performance varied significantly.
* Certain products showed stronger demand.
* Data analysis can support business decision-making.

## Conclusion

Retail sales analysis helps businesses understand customer preferences and optimize sales strategies through data-driven insights.
